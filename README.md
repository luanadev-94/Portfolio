# Portfólio Pessoal

Projeto acadêmico desenvolvido para a disciplina de **Desenvolvimento Web**, com foco na prática de **HTML5, CSS e JavaScript**.

O site é um portfólio com quatro seções (**Sobre mim**, **Formação**, **Projetos** e **Contato**), exibidas uma de cada vez por meio de um menu de navegação.

🔗 **Acesse o site:** [luanadev-94.github.io/Portfolio](https://luanadev-94.github.io/Portfolio/)

## Objetivos do projeto

- Praticar a estruturação de páginas com HTML5 semântico
- Aplicar estilos e layout com CSS
- Usar JavaScript para criar interação (troca de seções pelo menu)
- Aprender o fluxo básico de versionamento com Git e GitHub
- Publicar um site com GitHub Pages

## Funcionalidades

- Menu de navegação que alterna entre as seções sem recarregar a página
- Seções: Sobre mim, Formação, Projetos e Contato
- Hospedagem gratuita com GitHub Pages

## Tecnologias utilizadas

- **HTML5**: estrutura e conteúdo da página
- **CSS3**: estilização e layout
- **JavaScript**: interatividade do menu
- **Git e GitHub**: versionamento e publicação

## Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/luanadev-94/Portfolio.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd Portfolio
   ```
3. Abra o arquivo `index.html` no navegador (ou use a extensão **Live Server** no VS Code).

Não é necessário instalar nenhuma dependência.
